# Youssif Wagih Abounasser - Personal Portfolio

A bilingual English/Arabic professional portfolio documenting institutional development, training and visual content experience.

## Live website
https://youssifwagih.github.io/

English is the default language. The language button switches content and reading direction; Arabic is available at `?lang=ar`.

## Contents
- `index.html`: complete website with embedded Amiri fonts, portrait, styles and scripts.
- `cv/`: Arabic and English two-page, selectable PDF resumes. The download button selects the current website language.
- `.nojekyll`: serves the files as a plain static GitHub Pages site.

The only interactive work example is instant training. It uses illustrative inputs, topic mappings and local report downloads. Video files are not included and no reports are sent to an external service.

## GitHub Pages
Use the `main` branch and `/ (root)` as the publishing source. Private repositories require a GitHub plan that supports private-repository Pages. The repository can be private while the published portfolio remains publicly accessible.

Keep the `cv` folder alongside `index.html` when moving or deploying the website.
